# network-model-TCP-IP
A project I did a while ago, creating a data network model based on the TCP/IP architecture.

Maximal required count of end systems (ie. PC) in each subnet is:
A 511
B 332
C 360
D 413
E 446
F 88
G 131
H 401

VLSM was used to fulfill the requirements, and a network model was built in Cisco Packet Tracer, verifying all the connections between each of the end system via ping.

Full report is available in Project.pdf file.
